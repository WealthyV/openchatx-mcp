# 更新紀錄：2026-11-26 19:44

## 摘要

將 OpenChatX 版本提升至 1.4.3，修正 Web UI 工作階段操作、即時同步及私人網路存取的穩定性問題。

## 影響範圍

- 前端：Agent 儀表板、Subagent 工作階段、工具詳情及資料刷新機制。
- 後端：Subagent 刪除與 Tailscale 轉送規則管理。
- 測試：工作階段刪除、非同步請求競態及錯誤恢復。

## 變更內容

### 修正

- 避免過時的查詢回應覆蓋最新狀態，修正刪除後舊資料重新出現、快速切換工作階段時詳情顯示錯誤的問題。
- 重複點擊目前工作階段時保留詳情，工具紀錄離開近期列表後仍可查看已開啟的內容。
- 工作階段讀取失敗時顯示錯誤並支援重新載入；合併重複刷新請求，取消過時查詢。
- 允許儀表板重複刪除已移除的 Subagent 工作階段，維持原有代理工具的所有權限制。
- 將 Tailscale CLI 改為非同步執行，避免阻塞後端服務；定期檢查不再覆蓋尚未完成的使用者設定操作。

## 相容性與遷移

- 無需資料遷移；未變更既有存取權限或代理執行時間限制。

## 注意事項

- 儀表板讀取請求設有 15 秒逾時，與 Agent 任務執行時間無關。
- 新版桌面 App 需建置安裝後重新啟動才會套用全部修正。
